# Summit Climate Services demo cases

Use the case list in the dashboard to start a browser role-play. Speak as the customer. On cases without a plan, the agent opens with the balance and asks how you want to handle it; ask for a payment plan yourself if that is the branch you want to show. On Cedar Bakery's active-plan case, the agent opens with a scheduled-payment check-in. These are fictional accounts. Seeded prior emails have status `historical_mock` and were never sent by the app.
